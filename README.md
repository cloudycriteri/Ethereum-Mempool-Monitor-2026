<h1 align="center">Ethereum Mempool Monitor</h1>

<p align="center">
  <b>Real-time pending transaction tracker and analyzer for the Ethereum network on Windows.</b>
</p>

---

## What This Tool Does

- Connects to Ethereum nodes via RPC and WebSocket
- Streams real-time pending transactions from the mempool
- Advanced filtering by gas price, value, from/to address
- Custom alert system with notifications
- Transaction history and statistics
- Export data to JSON and CSV formats
- REST API for external integration
- Multi-node support for redundancy
- Works on Windows 10 and Windows 11

Ethereum Mempool Monitor is a professional tool for developers, traders, and researchers who need real-time visibility into pending transactions on the Ethereum network. It provides advanced filtering, alerting, and export capabilities. This is a fully functional application with no limitations.
